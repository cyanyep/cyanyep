# 动机面——why⭐

职业规划

请您先用1分钟左右的时间介绍一下自己吧！（语言表达、逻辑思维） 你为什么不选择本专业就业，而选择我们Xx呢？（目标设定、兴趣、认知）

你是如何

面试官你好，大学的时候，我们也开了职业规划课所以，当时的时候呢啊，我就做了一些基本的调研和了解后发现，我们化工方向未来就业可以从事什么所以我在大2升大3的暑假呢，就去了某某化工公司做了一个什么什么方向的实习在实习中，我接触了什么了解了什么也跟啊这个化工领域的一些同事做了沟通，我发现未来毕业的话，只能从事什么相关的工作，我觉得这个岗位不太适合我所以上了大3之后呢我就去做了一些行业的了解调研，我发现互联网运营主要是做什么的，它需要什么能力而我大学的时候也自学了psp剪映还负责我们学校的什么公众号的运营我觉得这些方面呢，我比较喜欢和擅长所以，最终，我选择方向的时候就选择了互联网运营岗方向没有选择自己本专业化工领域。

# 为什么选择我们公司

职业规划

个场景比你面试的是一个sales,你应聘的是个销售岗位啊听应聘的是销售岗位，但你第一段经历的是在大2的时候在你们学院里的办公室做过助理。办公室助理做了3个月，第2，个呢，是第二段经历呢，是你在大学的时候比如说你在外联部我不知道你们叫什么部门哈反正就是学生会有个部门叫外联部啊。在外联部拉过比如说，5000块钱的赞助。小伙伴各位弟弟妹妹听一下，你现在应聘的是个sales或者应聘的是个bd啊，bd啊，就商务拓展哈大家听一下，你觉得你讲哪一段经历好。

# 您怎么评价自己？简单说一下自己的优缺点？（自我认知）

缺点不能致命。缺点+改正措施+现在的结果

候一定讲个真实你说老师我过于追求完美，也是真实的滚拍死

第3，个就你，定要有一定的改进措施就当你发现自己有缺点的时候你已经改进比如说，老师，我发现最大缺点就是我的演讲能力不太好，我表达能力比较弱，是吧，这是事实吧，当然是事实，你是如何发现的怎么认识的呢？你可能在你们学校里的班会上，可能参加一个什么活动的招牌发言的时候你觉得自己，紧张，从那开始，你就意识到自己。表达能力有点问题是吧，你要一定要有改进措施，你是如何改进的比如说，从那开始，我就参加了我们学校的什么什么演讲辩论协会我就积极参加学校的辩论赛经过这2年左右的训练如果再让我在什么这么着，我会做到怎么着后续我还会加大这块的学习成长然后提高自己这方面能力就你简单讲一讲就ok了
