# 面试问题

自我介绍：

面试官好，非常感谢能给我这次机会，我是XX大学XX专业的26届本科毕业生，我今天来应聘软件开发工程师这个岗位，在大学期间，我系统学习了软件需求分析、软件工程、Web 前端设计与开发、JAVA 框架技术、数据库系统原理等核心课程，这些课程为我打下了扎实的软件开发理论基础，并积累了相关的课程设计经验，我认为这些课程内容与贵公司该岗位的要求有较高的匹配度。然后我有过一段实习经历，在实习中负责项目的功能文档和接口文档设计和具体的功能开发，收获了相关的后端开发经验，

此外，我还开发了两个项目，分别是快易点和校园美食圈，

快易点项目是一个定制的项目，主要是为商家提供一个点餐系统，商家可以管理菜品，用户可以浏览并点餐，项目中主要使用JWT令牌+拦截器和ThreadLocal来实现用户的登录校验，还有使用Redis将热点商品进行缓存，通过RabbitMQ的一个死信队列插件实现订单的超时自动取消

而校园美食圈是一个类似于大众点评的项目，用户可以查询附近的商户以及其他用户对这些商户的评价笔记，这个项目主要是通过Redis实现的，通过Redis+Token和拦截器的方案来实现用户的登录校验，项目中对高并发的秒杀优惠券部分，使用Redis分布式锁来实现一人一单，由于锁的粒度太大，我使用Lua+redis来实现抢单并使用RabbitMQ异步实现数据库库存扣减和订单生成的操作

如果有对哪个感兴趣的可以具体提问，

非常荣幸能获得今天这个交流的机会，我希望能沟通愉快

作为软件工程专业的学生，贵公司的该岗位符合我的发展规划。所以希望有机会加入贵公司

# 自我介绍

面试官好，非常感谢能给我这次机会，我是XX大学XX专业的26届本科毕业生，我应聘的岗位是软件开发工程师，在大学期间，我系统地学习了软件需求分析、软件工程、Web 前端设计与开发、JAVA 框架技术、数据库系统原理等核心课程，这些课程为我打下了扎实的软件开发理论基础，并积累了相关的课程设计经验，我认为这些课程内容与贵公司该岗位的要求有较高的匹配度。然后我有过一段JAVA后端的实习经历，在实习中负责项目的功能文档和接口文档设计和具体的功能开发，收获了相关的后端开发经验，

此外，我还完成了两个项目，收获了相对应的后端开发经验

最后，作为软件工程专业的学生，贵公司的软件开发工程师岗位符合我的发展规划。所以希望有机会加入贵公司

# 职业规划

近期规划：进入公司后，积极参加新人培训，尽快熟悉并掌握岗位的工作内容，做好自己的本职工作，多向公司的前辈学习请教，

远期规划：积累了一定的岗位知识和工作经验后，可以在这个岗位上发挥自己的作用，承担更多的职责，配合公司和行业的发展

对于职业规划，我暂时是这么考虑的

# 为什么选择我们公司

贵公司是企业营销数字化服务商，为企业提供数字化转型的平台，企业营销数字化是当前发展的方向，我觉得贵公司的发展方向有前途，并且可以锻炼到个人综合能力，符合我的职业规划和预期，所以希望有机会加入贵公司

# 核心竞争力

我觉得我的核心竞争力

对工作充满责任感，

而且我的专业软件工程也符合贵公司该岗位的要求，符合我的发展规划

# 评价自己

之前在期末周做大作业时容易纠结细节拖进度，导致最后花费太多时间在大作业上的不重要、对最终的分数影响不大的功能上，（缺点），最后不够时间在，后来我会提前列优先级清单，把核心任务标红，上周负责的方案还提前1天交付（行动+结果）”，既真实又显解决能力！

追求完美，之前在考试周时，我会在太多时间在大作业上，完成一些不重要的功能，导致考试准备的时间不够，后面我

注重规划与准备。在做某件事前，我都会先搜集好信息、做好准备，确保自己全面理解目标、流程和潜在风险。这种习惯，能让我在后续执行中方向清晰、效率更高，保证工作成果的质量和稳定性。

# 入职后如何展开工作

尽快熟悉并掌握岗位的工作内容，快速了解团队的工作流程、项目目标、业务背景以及我在团队中的角色和期望。熟悉工作所需的工具，为迅速投入工作做好准备。

# 岗位不适合

由于刚进入职场，不能很好的适应公司的环境和工作节奏，我会制订好计划，自主学习，向同事请教等方法，让自己尽快去适应工作，

# 没有什么经验，能胜任这份工作吗

我没有直接的工作经验，这是事实，但是我在学校期间做过不少项目，锻炼了我的XX/沟通，执行和解决问题的能力，这跟工作所需要的是相通的，加上我的学习能力很强，加入公司后，我会尽快补齐差距，把岗位锁需要的技能掌握好，我不觉得经验不足是障碍，反而让我更有动力去证明自己

# 你的性格很内向

内向是我的性格，但不是我的工作作风，我习惯先倾听在表达，所以跟团队合作起来，反而更高效，同时内向的性格，让我更专注、细致。这些特性也能让我在工作中更有条理和可靠

# 薪资对你重要吗

薪资对我来说确实很重要，因为他代表公司对我的认可，但我不会只看着薪资， 我更看重的是，能不能再这个岗位上持续成长，以及公司和个人目标是不是匹配

# 手上还有其他offer吗

我这两天才正式启动面试，这次求职我更看中适配度，所以只筛选了几家意向度较高的公司投递，目前有两家还在流程推进中，暂时没收到offer，不过和您沟通下来，我特别认可贵公司的就业前景，聊的也很愉快，相比之下更倾向加入贵团队
