# 看到你的简历，很适合我们XX岗位

感谢您的认可！请问后续流程如何安排

# 请问最近在看机会吗

目前我在积极关注与职业规划匹配的机会，尤其对贵公司的XX很感兴趣，我具备XX的经验，过去在某领域取得了XX成果。如果有与XX相关的机会。很乐意深入交流

# 打招呼

我对您发布的XX岗位很感兴趣，希望能够跟您沟通一下，我大学学的是软件工程专业，之前在XX公司有过实习经验，内容是XX，锻炼了XX能力，符合您的岗位要求。我这边把简历发您看看可以吗

# 面试结束

中午好，非常感谢您今天为我面试花费的时间和精力，与您的交谈非常愉快也让我更加明确了自己的工作目标。因为我的面试经验没有那么丰富，可能说话应对方面没有那么周到，还请您包涵！我希望能够做好这个岗位，所以非常渴望能拥有这个机会。如果有结果也请您知会我一下，感谢您给我这次电话面试的机会，祝您工作顺利
